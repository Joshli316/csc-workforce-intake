# CSC Workforce Intake

Bilingual (English/Traditional Chinese) online intake form for the Chinatown Service Center's Workforce Development department in Los Angeles. Replaces the paper PDF + manual Excel entry workflow. Submissions land directly in a Google Sheet; signatures save as PNG to a Drive folder.

## Tech Stack
- Vanilla HTML / CSS / JavaScript single-page app — no framework, no build step
- Backend: Google Apps Script Web App (one POST endpoint, action field switches behavior)
- Storage: one Google Sheet (rows) + one Drive folder (signature PNGs)
- Hosting: Cloudflare Pages (`wrangler pages deploy dist/`)

## Structure
```
csc-workforce-intake/
  index.html          — the form (client + staff mode)
  styles.css          — Civic-warm design system
  script.js           — form logic, wizard, signature pad, draft autosave, POST
  apps-script/
    Code.gs           — Apps Script backend (paste into script.google.com)
    README.md         — deploy steps for the Web App
  README.md           — project overview + setup steps for staff
```

## Entry Point
`index.html` — deployed at root. Single page; client/staff toggle inside.

## Deployment
- `wrangler pages deploy .` (no build step; flat HTML)
- Apps Script: deploy as Web App, "Execute as me", "Anyone" access. Copy the `/exec` URL into `script.js` as `APPS_SCRIPT_URL`.
- After first push to GitHub: `git remote set-head origin --auto`

## Conventions
- **Bilingual**: every visible string is in both English and Traditional Chinese. Default to Chinese on first load (LEP audience). Language toggle at top right. Update `html[lang]` on toggle (screen-reader voice selection).
- **i18n approach**: `data-en` / `data-zh` attributes on every label/option; one `applyLang()` function flips them.
- **Modes**: `?mode=client` (default, wizard, 18px+) vs `?mode=staff` (single dense page, fast tab order). Staff mode also auto-fills Intake Date and remembers Staff Name in localStorage.
- **Autosave**: every input change saves to `localStorage.workforceIntakeDraft`. Cleared on successful submit. "Clear & start new" button in staff mode.
- **Signature**: HTML5 canvas, 480x180px, black ink on cream. Saved as base64 PNG in submit payload; Apps Script writes it to Drive folder and stores the file URL in the row.
- **Reference number**: generated by Apps Script as `WD-YYYY-NNNN` (sequential per year). Returned to the page and shown on success screen.
- **Required fields**: Last Name, First Name, DOB, Phone, Signature, Date. Everything else can be blank (clients may decline).
- **Privacy**: SSN is collected but stored as-is in the Sheet. The Sheet must be shared with named staff only — never "anyone with link." Add a banner in the Apps Script setup README.
- **Print fallback**: a "Print blank form" button generates a clean PDF view via `window.print()` with `@media print` styles, for when WiFi is down.
- **No login**: anyone with the URL can submit. Rate limit by IP in Apps Script (max 30/hour per IP) to deter abuse.

## Accessibility
- 18px body minimum (LEP audience reads small text poorly)
- All inputs have `<label for="">` pairs
- Visible focus rings, keyboard-navigable
- High contrast (WCAG AA): body text ≥ 4.5:1 against background
- Touch targets ≥ 44x44px (tablet-friendly)
- `html[lang]` updates on toggle

## Data flow
```
Client/Staff fills form
  → JS validates required fields
  → POST {action: 'submit', data: {...}, signature: 'data:image/png;base64,...'} to Apps Script
  → Apps Script:
      1. Generate ref number (WD-2026-NNNN)
      2. Save signature PNG to Drive folder, get URL
      3. Append row to Sheet with all fields + signature URL + ref number + timestamp
      4. Send confirmation email to workforce@cscla.org
      5. Return {ok: true, ref: 'WD-2026-0142'}
  → Page shows success screen with ref number + "what's next"
```

## Out of scope (v1)
- Editing past submissions from the web (do it in the Sheet directly)
- Multi-user accounts / login
- Document upload (resumes etc.) — link to a separate Drive folder later if needed
- SMS/email to client after submit (no consent flow yet)
